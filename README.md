# 💡 بوت الاقتراحات ・ مجاني من Codeon

العضو يكتب اقتراحه في الروم، والبوت يحذف رسالته ويحوّلها لإمبد مرتب فيه تصويت ✅ ✖️، وأزرار قبول ورفض للإدارة.

## ✨ المميزات
- إمبد مرتب فيه صورة العضو، والحالة، ونسبة التصويت.
- تصويت يقدر العضو يغيّره أو يشيله، وصاحب الاقتراح ما يصوّت على اقتراحه.
- قبول ورفض بسبب، ويتغير لون الإمبد للأخضر أو الأحمر.
- صاحب الاقتراح يوصله القرار في الخاص.
- ثريد نقاش تحت كل اقتراح، وينقفل بعد القرار.

## ⚙️ التشغيل
1. نزّل Node.js 18 أو أحدث.
2. اكتب `npm install`.
3. انسخ `.env.example` وسمّه `.env`، وحط فيه السطر `TOKEN=توكن_البوت`.
4. اكتب `npm start`.

من Developer Portal فعّل **Message Content Intent**.
